输入：[技术设计 §9](../../../High-Level-Design.md)、SDK 工具协议及原网络页面。所有请求正常校验 TLS；不建立通用代理、不自动重放未知外部执行。状态见 [Progress](../../../Progress.md)。

<a id="e1"></a>
## E1：浏览器 IP 与 WebSocket

**前置任务：B2、C1。**

**目标：** 保留访问者网络位置的查询和调试体验，避免后台位置变化带来错误解释。

**修改范围：** 原 `tools/ip/Ip.vue`、`tools/websocket/Websocket.vue` 及相应取消、日志和测试。

**执行步骤：** GeoJS 从浏览器请求，IP 校验使用现有解析能力，指定 IP 与“当前公网 IP”分开。WebSocket 继续使用浏览器标准 API，支持连接/发送/接收/断开；限制帧、日志和 bufferedAmount，卸载清理监听/连接；HTTPS 不能连接 ws:// 时如实提示，不静默切服务器隧道或自动重发。

**验收：** 查询成功/无效 IP/外部失败/超时；实际浏览器 CORS；WebSocket 正常收发、连接失败、队列上限、断开后不重发和切页清理。开发机 HTTP 探测不能替代浏览器验证。

**证据：** 浏览器网络与 UI 断言、实际请求来源、取消/断开计数；受浏览器策略限制的行为明确列出。

## E2：ARM 固定服务适配

**前置任务：B3、C1。**

**目标：** 保留 ARM↔机器码的架构、offset、端序和输出选项，去除旧公共代理依赖。

**修改范围：** 原 `tools/arm/util.ts`、两个页面的桥调用、服务固定目标适配及相关工具定义/测试。工具定义由 C4 入口生成，不手工维护第二份。

**执行步骤：** 请求经宿主工具桥进入 Node，目的地址固定为官方转换端点；校验 asm/hex/offset/arch，限制负载/响应/截止时间。工具 `ai=false,mcp=false`。结果逐架构核对 `[成功标记,内容]`，部分失败独立反馈，不能将 HTTP 200 当所有架构成功。

**验收：** ARM64 已验证样例作为回归，补 ARM/Thumb/大端/无效偏移/非法机器码/部分架构失败/超时/无效响应；不接受传入 URL/上游头，不依赖原公共代理，不伪造本地转换结果。

**证据：** 固定目标请求和参数映射、逐架构结果、失败路径；单次公共服务成功不当作 SLA 或全部架构通过。

<a id="e3"></a>
## E3：JDoodle 在线运行与额度查询

**前置任务：B2、B3、C1。**

**目标：** 保留原单文件在线执行，不在 cookieOS 管理服务器运行用户代码。

**修改范围：** 原 `tools/code/Run.vue`、`runUtil.ts`、旧浏览器凭据设置、服务 JDoodle 适配与相关定义/测试；代码格式化仍归 C1。

**执行步骤：**
1. 秘密配置键为 `jdoodleClientId/jdoodleClientSecret`，只在服务映射到上游 clientId/clientSecret；UI/历史/日志/错误不含凭据。
2. 复用 [官方 REST](https://www.jdoodle.com/docs/api/rest)、[语言版本](https://www.jdoodle.com/docs/api/languages)、[错误合同](https://www.jdoodle.com/docs/api/errors)，核对版本索引，不把旧列表当最新。
3. 固定执行和额度地址，仅接受所需语言/版本/代码/标准输入字段；不新增任意服务器命令、多文件、第三方库安装或付费联网权限。
4. 在线执行标 dangerous，ai/mcp 均为 false，需用户主动触发；缺配置指明配置入口。外部 HTTP、业务 error、编译器输出与用户程序逻辑成功分开。
5. 设置超时/响应上限并拒绝会泄漏凭据的重定向；丢失返回后显示未知，不能编造上游幂等查询或重新提交。

**验收：** 假上游核对请求字段与凭据仅在服务内；模拟 HTTP 200 带 error、认证失败、限流、编译失败、返回丢失、超限、超时。对丢失返回场景断言实际执行请求数为 1；代码中不能走 Node eval/child_process 等执行路径。

**证据：** mock 网络/状态断言、配置缺失行为；真实执行须有受授权测试账号/凭据并使用无文件无网络示例，缺少时只阻塞真实验证，不能购买服务或把功能占位当完成。
