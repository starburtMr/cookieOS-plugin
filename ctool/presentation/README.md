# 使用说明

把常用的编码转换、数据处理、文本编辑和开发调试工具放在一起。通过顶部分类浏览，或输入名称搜索工具；选择功能后填写文本、上传文件或调整选项，再查看、复制或下载结果。

## 功能概览

- 加密与安全：摘要、HMAC、对称加解密、签名校验及密码生成。
- 编解码：Base64、URL、Unicode、JWT、十六进制和压缩转换。
- 数据处理：JSON、配置格式转换、序列化、进制和数据标识处理。
- 文本工具：替换、排序、去重、正则、文本比较及代码格式化。
- 网络与 Web：IP 查询、URL 解析、WebSocket、HTTP 代码片段和请求信息解析。
- 开发辅助：Cron、SQL 参数填充、堆栈、权限、数据校验、颜色、单位和时间处理。
- 生成器：二维码、条形码、UUID、随机文本及网络地址计算。

各项能力以当前工具页面的输入、选项和结果为准。

## 开始使用

在 cookieOS 安装扩展后打开工具箱，选择分类或搜索工具。设置中可调整语言、主题、缩放和常用工具。首次操作可使用示例数据；确认结果后再复制或下载。

## AI 辅助

带 AI 标记的功能可辅助处理 JSON、正则、Cron、SQL、堆栈、配置转换、HTTP 片段、代码、文本、文本比较、URL 和 User-Agent。先在 cookieOS 配置可用模型，再在工具箱设置选择跟随默认模型或指定模型。

主动点击 AI 操作时，本次输入会发送给所选模型，可能产生模型服务费用。结果需确认后点击「使用结果」；修改输入或离开当前工具后，旧结果不会自动应用。模型生成可能不准确，尤其是代码、SQL 和正则，请检查后使用。断流或超时后先查询原调用状态，不要反复提交。

## AI 与 MCP 工具调用

现有页面能力已扩展为100个AI/MCP工具名称，涵盖编码、数据、密码学、文本代码、时间计算、图像与联网操作；原14个接口保持兼容。工具名不等于页面入口数。复杂结果以JSON文本返回，大文本和文件通过临时引用分块读取。

通过模型辅助接口可开始生成、查询状态和取消。13种操作对应页面中的12类辅助，使用同一提示词；生成可能产生费用，不会自动运行生成的代码。密码学接口的keyRef引用扩展秘密配置中的keys对象。临时文件最多8 MiB输入、16 MiB输出，空闲15分钟过期，重启后引用失效。
宿主 AI 或外部 MCP 使用前，需在扩展设置启用对应开关。外部 MCP 还需在 cookieOS「MCP 服务」选择插件工具并配置访问令牌。界面模型选择与宿主AI/MCP开关分别配置。

## 联网与必要配置

- 页面IP查询和WebSocket从浏览器连接；AI/MCP接口从管理服务器连接，出口与浏览器可能不同。HTTPS页面可能限制不安全的WebSocket连接。
- ARM 转换由 cookieOS 管理服务器访问外部转换服务。
- 在线代码运行使用 JDoodle，可能消耗外部额度。需在扩展的秘密配置中填写 `jdoodleClientId` 和 `jdoodleClientSecret`，未配置时其他工具仍可使用。代码由外部服务执行；超时不代表未执行，先确认结果再重试。

## 使用限制与数据

较大的输入、文件或耗时计算可能达到工具限制，请按提示缩小内容。AI 需要宿主提供模型接口；无模型时普通工具仍可使用。剪贴板受浏览器权限和安全上下文限制，局域网 HTTP 下可能不可用。

偏好设置保存在 cookieOS。工具历史默认关闭，即使开启也仅在当前页面会话保留，密码、密钥和代码等敏感工具不记录历史。本次更新保持已有配置及存储键，不迁移或清空用户数据。
