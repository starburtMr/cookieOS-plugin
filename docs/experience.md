# 共享开发经验

通用接入规则见 [开发约定](development.md)，市场规则见 [市场维护](market.md)。本页只沉淀经过验证、能被后续插件复用的结论，不重复复制协议文档。

## 记录方法

每条经验记录日期、适用插件或版本、问题现象、原因、处理方法、验证依据及失效条件。详细证据放在相关插件目录，本页链接到来源。未经验证的判断标注为待验证，不作为强制规则。

插件专属业务留在插件目录。SDK 或宿主升级时复核受影响结论；过期结论标注失效原因并链接替代方法。记录不得包含凭据、用户数据或开发机私有路径。
